Detailed Description

The statistics of a message connector (dxfg_v4_MessageConnector_getStatistics()).

The counters cover all the connections of the connector since it was created, the closed ones included. The layout of the struct does not change: new counters will come with a new function.

On iOS and the iOS Simulator, read_data_records and written_data_records stay 0: the SDK of these platforms has no QD monitoring (qds-monitoring), which keeps the statistics they come from. The other counters work there too.

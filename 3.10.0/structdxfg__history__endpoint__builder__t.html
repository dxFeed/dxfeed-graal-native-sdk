Detailed Description

A handle of a builder of history endpoints (Java HistoryEndpoint.Builder); release it with dxfg_JavaObjectHandler_release().

Create it with dxfg_HistoryEndpoint_newBuilder(), set the parameters with the dxfg_HistoryEndpoint_Builder_with*() functions (they change this builder) and create an endpoint with dxfg_HistoryEndpoint_Builder_build(). The builder stays valid after that: it can be changed and used to build more endpoints.

Detailed Description

The client of the history (candle web) service: a request of the time series events of a symbol within a time range over HTTP, configured with a builder.

dxfg_HistoryEndpoint_newBuilder() creates a builder, the functions dxfg_HistoryEndpoint_Builder_withAddress(), dxfg_HistoryEndpoint_Builder_withUserName() and the other dxfg_HistoryEndpoint_Builder_with* functions set its parameters and dxfg_HistoryEndpoint_Builder_build() creates the endpoint, which dxfg_HistoryEndpoint_getTimeSeries() uses to request the events.

A handle that a function returns is owned by the caller: release it with dxfg_JavaObjectHandler_release() (see the group Javac for the ownership rules). All the functions of this group return DXFG_EXECUTE_SUCCESSFULLY (0) or DXFG_EXECUTE_FAIL (-1) on error, and the result is passed through an [out] parameter; it is not changed on error. A NULL [out] pointer is an error too. dxfg_get_and_clear_thread_exception_t() gives the exception.

A handle of a builder of history endpoints (Java HistoryEndpoint.Builder); release it with dxfg_JavaObjectHandler_release().

Create it with dxfg_HistoryEndpoint_newBuilder(), set the parameters with the dxfg_HistoryEndpoint_Builder_with*() functions (they change this builder) and create an endpoint with dxfg_HistoryEndpoint_Builder_build(). typedef struct dxfg_history_endpoint_t dxfg_history_endpoint_t

A handle of a history endpoint, the client of the history service; release it with dxfg_JavaObjectHandler_release().

Create it with dxfg_HistoryEndpoint_Builder_build(). The endpoint holds only the settings of the requests: it does not keep a connection open, there is nothing to close. Releasing the handle drops the reference to the settings.

int32_t dxfg_HistoryEndpoint_getTimeSeries ( graal_isolatethread_t * thread,
dxfg_history_endpoint_t * endpoint,
dxfg_event_clazz_t eventClazz,
dxfg_symbol_t * symbol,
int64_t fromTime,
int64_t toTime,
DXFG_OUT dxfg_event_type_list ** events )

Requests the time series events of a symbol within a time range from the history service.

The function blocks the calling thread while the request is executed and the response is read: it sends a request to the address of the endpoint with the query parameters records (the simple name of the event class), symbols, start and stop (the range), format and compression (the settings of the endpoint), then decompresses and parses the response. It fails if the request, the reading or the parsing fails.

eventClazz must be the class of a time series event (for example DXFG_EVENT_CANDLE or DXFG_EVENT_TIME_AND_SALE); the sources do not say what happens for another class.

Java: HistoryEndpoint.getTimeSeries(Class, Object, Long, Long).

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]endpointThe history endpoint.
[in]eventClazzThe class of the events to retrieve.
[in]symbolThe symbol whose time series is requested; its string form is sent to the service. The caller keeps its ownership.
[in]fromTimeThe start of the time range, in milliseconds since the Unix epoch.
[in]toTimeThe end of the time range, in milliseconds since the Unix epoch.
[out]eventsThe list of the events of the specified class and symbol within the time range; it can be empty. Release it with dxfg_CList_EventType_release().
Returns

The default settings are:

  • DXFG_HISTORY_ENDPOINT_COMPRESSION_ZIP as the compression;

The address, the user name, the password and the authentication token are not set.

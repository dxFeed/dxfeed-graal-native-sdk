Detailed Description

The builder of endpoints (Java DXEndpoint.Builder).

The recommended way to create an endpoint: the builder allows to set the role, the name, the executor and the properties (see DXEndpoint.Builder). Every dxfg_DXEndpoint_Builder_build() call creates a new endpoint.

dxfg_endpoint_t * dxfg_DXEndpoint_Builder_build ( graal_isolatethread_t * thread,
dxfg_endpoint_builder_t * builder )

Builds a new endpoint with the builder's settings.

Every call builds a new endpoint. An endpoint with the role DXFG_ENDPOINT_ROLE_FEED or DXFG_ENDPOINT_ROLE_PUBLISHER connects automatically on creation if dxfeed.address (feed) or dxpublisher.address (publisher) is set; the endpoints of the other roles do not.

Java: DXEndpoint.Builder.build().

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]builderThe builder.
Returns
The new endpoint, or NULL on error. Use dxfg_get_and_clear_thread_exception_t() to get the exception. The caller owns the endpoint: close it with dxfg_DXEndpoint_close() or dxfg_DXEndpoint_closeAndAwaitTermination() and free its handle with dxfg_JavaObjectHandler_release() (releasing the handle does not close the endpoint).

int32_t dxfg_DXEndpoint_Builder_withExecutor ( graal_isolatethread_t * thread,
dxfg_endpoint_builder_t * builder,
dxfg_executor_t * executor )

Sets the executor of the notifications of the endpoints built by this builder: event processing, state changes, etc.

Use it instead of the deprecated dxfg_DXEndpoint_executor().

By default, the endpoint uses a thread pool with the size equal to the number of available processors (the dxfeed.threadPoolSize property for the feed roles and dxpublisher.threadPoolSize for the publisher). The executor must not reject the submitted tasks.

Java: DXEndpoint.Builder.withExecutor(Executor).

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]builderThe builder.
[in]executorThe executor (e.g. from dxfg_Executors_newFixedThreadPool()) or NULL to use the default one. The builder does not take the handle: free it with dxfg_JavaObjectHandler_release() when it is no longer needed.
Returns
DXFG_EXECUTE_SUCCESSFULLY (0) on successful function execution or DXFG_EXECUTE_FAIL (-1) on error. Use dxfg_get_and_clear_thread_exception_t() to determine if an exception was thrown.

Sets the properties of the endpoints built by the builder from a properties file.

The file is read in the format of a Java properties file (java.util.Properties.load) and every property that the builder supports is set as by dxfg_DXEndpoint_Builder_withProperty(). The unsupported properties are ignored. An error is reported if the file cannot be read.

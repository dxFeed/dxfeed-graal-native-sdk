Detailed Description

The recommended way to create an endpoint: the builder allows to set the role, the name and the properties (see DXEndpoint.Builder). Every dxfg_DXEndpoint_Builder_build() call creates a new endpoint.

int32_t dxfg_DXEndpoint_Builder_withExecutor ( graal_isolatethread_t *  thread,
dxfg_endpoint_builder_t *  builder,
dxfg_executor_t *  executor 
)

Sets the executor of the notifications of the endpoints built by this builder: event processing, state changes, etc. (DXEndpoint.Builder.withExecutor(executor)). Use it instead of the deprecated dxfg_DXEndpoint_executor().

By default, the endpoint uses a thread pool with the size equal to the number of available processors (the dxfeed.threadPoolSize property for the feed roles and dxpublisher.threadPoolSize for the publisher). The executor must not reject the submitted tasks.

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]builderThe builder.
[in]executorThe executor (e.g. from dxfg_Executors_newFixedThreadPool()) or NULL to use the default one. The builder does not take the handle: free it with dxfg_JavaObjectHandler_release() when it is no longer needed.
Returns
DXFG_EXECUTE_SUCCESSFULLY (0) on success or DXFG_EXECUTE_FAIL (-1) on error. Use dxfg_get_and_clear_thread_exception_t() to get the exception.

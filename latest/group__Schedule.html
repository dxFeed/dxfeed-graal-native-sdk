Detailed Description

Trading schedules of exchanges and instruments: schedules, days, sessions and the filters to search them.

All times are UTC milliseconds since the Unix epoch (1970-01-01T00:00:00Z). The supported date range is from 0001-01-02 to 9999-12-30.

Every function that returns a handle (a schedule, a day, a session or a filter) creates a new handle that the caller owns, even if the same Java object has been returned before: release it with the function named in its description.

typedef int32_t(*) dxfg_day_filter_function(graal_isolatethread_t *thread, dxfg_day_t *day)

A custom day filter function: tests whether a day is an acceptable result of a search.

The function is called by the search function that uses the filter (for example dxfg_Day_findNextDay()), on the thread that called that search function, possibly several times during the call.

The day handle is created for this call and the SDK does not release it afterwards: release it with dxfg_Day_release() unless it is needed later.

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]dayThe day to test.
Returns
1 if the day is accepted; any other value rejects it.

◆ dxfg_day_t

typedef struct dxfg_day_t dxfg_day_t

A handle of a Java Day object; release it with dxfg_Day_release().

A day is a continuous period of time about 24 hours long, aligned to the business hours of the schedule, so days start and end at various local times. Days do not overlap: they form a chain of adjacent periods, and the point on the border belongs to the day that starts there. A day consists of sessions and is a trading day if at least one of them is a trading session.

◆ dxfg_session_t

typedef struct dxfg_session_t dxfg_session_t

A handle of a Java Session object; release it with dxfg_Session_release().

A session is a continuous period of time with the same rules for trading activity. It is either trading or non-trading and lies inside one day. Sessions do not overlap: they form a chain of adjacent periods, and the point on the border belongs to the session that starts there. A session may have zero duration (an empty session).

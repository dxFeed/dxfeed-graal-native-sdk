◆ event_time

int64_t dxfg_market_event_t::event_time

The time when the event was created, in milliseconds since the Unix epoch (UTC), or 0 if not available. It is available only if the endpoint is created with the event time property and the data source has embedded event times, which is typically the case for historical tape files and OnDemandService only.

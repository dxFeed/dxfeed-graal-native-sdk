◆ dxfg_instrument_profile2_t

typedef struct dxfg_instrument_profile2_t dxfg_instrument_profile2_t

The fields of an instrument profile in a plain C structure, with the handle of its custom fields.

The strings are UTF-8 null-terminated strings that belong to the structure (an empty string if the field is not set). A structure that the SDK fills is released with dxfg_instrument_profile_free() (a single profile, see dxfg_Iterable_InstrumentProfile_next2()), dxfg_instrument_profiles_array_free() (an array) or dxfg_instrument_profile2_list_free() (a list): that frees the strings and releases the custom fields handle.

A structure that is passed to the SDK, e.g. to dxfg_InstrumentProfileCollector_updateInstrumentProfile2(), is only read: the SDK copies the strings, does not keep or free the pointers, treats a NULL string as an empty one and ignores instrument_profile_custom_fields_hash.

The custom fields are not copied: the Java instrument profile and the custom fields handle of the structure share the same storage of the fields, both in a structure that the SDK fills and in a structure passed to the SDK. A change made with dxfg_InstrumentProfileCustomFields_setField() and the like through that handle may change the profile (e.g. the profile in a collector). To change the custom fields independently, make a copy with dxfg_InstrumentProfileCustomFields_new3() first.

Every field is described with the corresponding dxfg_InstrumentProfile_get*() function.

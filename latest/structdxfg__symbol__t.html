dxfg_symbol_type_t type

Detailed Description

The base structure of every symbol: the first field of all the symbol structures.

type tells which of the structures dxfg_string_symbol_t, dxfg_candle_symbol_t, dxfg_wildcard_symbol_t, dxfg_indexed_event_subscription_symbol_t and dxfg_time_series_subscription_symbol_t the pointer really points to; cast the pointer to it to read the other fields.

A symbol created by dxfg_Symbol_new() or returned by the SDK is released with dxfg_Symbol_release() (a list of symbols with dxfg_CList_symbol_release()): that frees the structure, its strings and the nested symbols and sources.

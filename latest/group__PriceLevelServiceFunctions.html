Returns the order sources and the symbols of each order source that are available to the client.

The order sources and the symbols are filtered according to the permissions of the client. The view is built as of now: the result contains only the existing data (for example, no symbols that were delisted). Read the result with dxfg_AuthOrderSource_getByIds() or dxfg_AuthOrderSource_getByOrderSources().

DXFG_OUT dxfg_event_type_list ** orders )

Returns the price levels (orders) of a candle symbol within a time range.

The orders are sorted in ascending order by time.

The candle symbol shall contain a supported CandlePeriod and a custom attribute called granularity with the key GRANULARITY_ATTRIBUTE_KEY ("gr"). The granularity value shall be an integer in seconds; the minimal value is 1 second. If the CandlePeriod or the granularity is not supported by the service, the result is an empty list.

Java: PriceLevelService.getOrders(CandleSymbol, int, long, long, String), the order source is passed by its id.

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]serviceThe PriceLevelService.
[in]candleSymbolThe candle symbol to request: a dxfg_candle_symbol_t (type CANDLE); the call fails for another kind of symbol. The caller keeps its ownership.
[in]orderSourceThe order source to request: a dxfg_indexed_event_source_t of the type ORDER_SOURCE; the call fails for another kind of source. The caller keeps its ownership.
[in]fromThe "from" time in UTC (the unit is not stated by the Java documentation).
[in]toThe "to" time in UTC (the unit is not stated by the Java documentation).
[in]callerThe caller identifier: a UTF-8 null-terminated string that is passed to the service as is.
[out]ordersThe list of the order events (dxfg_event_type_list), possibly empty. Release it with dxfg_CList_EventType_release().
Returns
DXFG_EXECUTE_SUCCESSFULLY (0) on successful function execution or DXFG_EXECUTE_FAIL (-1) on error. Use dxfg_get_and_clear_thread_exception_t() to determine if an exception was thrown.

const char * address,
DXFG_OUT dxfg_price_level_service_t ** service )

Creates a client of the price level service and connects it to an RMI endpoint.

The client is an RMI client endpoint that is connected to the address; the service is its proxy. The handle of the client is written to service. Close the connection with dxfg_PriceLevelService_close().

Java: new PriceLevelServiceHolder(String) (the SDK class that wraps RMIEndpoint and PriceLevelService).

dxfg_java_object_handler_list list

Detailed Description

A list of promise handles.

A list that a function returns is allocated by the SDK: release it with dxfg_CList_JavaObjectHandler_release(), passing the field list (there is no release function specific to this list). That releases every promise handle, the array of the handles and the list itself.

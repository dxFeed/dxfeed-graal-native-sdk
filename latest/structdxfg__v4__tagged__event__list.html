Detailed Description

A list of events with a tag for each: the list returned by dxfg_v4_EventQueue_pollTagged().

Its first two fields are those of dxfg_v4_event_type_list, so the same code can read the events. Release it with dxfg_v4_tagged_event_list_release(), not with dxfg_v4_event_type_list_release() (the tags would leak).

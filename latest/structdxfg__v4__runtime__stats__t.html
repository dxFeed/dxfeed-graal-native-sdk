Detailed Description

The runtime statistics of the isolate and its process (dxfg_v4_system_get_runtime_statistics()).

Every field is -1 when the platform or the garbage collector does not give the value, otherwise it is 0 or more. Each value is read on its own, so the struct is not one atomic snapshot: a heap value and a GC count may come from moments around one collection. The layout of the struct does not change: new values will come with a new function.

The heap pool and GC fields follow the Serial GC, the GC of the SDK builds. A build with another GC (G1) has no such pools and collectors, and these fields are -1 there. allocated_bytes is -1 on every platform with GraalVM 25.5. The values were checked on Linux x64, macOS arm64 and Windows x64.

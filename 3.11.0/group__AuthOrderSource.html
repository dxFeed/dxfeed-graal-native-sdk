◆ dxfg_auth_order_source_t

typedef struct dxfg_auth_order_source_t dxfg_auth_order_source_t

A handle of Java AuthOrderSource: the information about the symbols that are available to the client for the entitled collection of order sources; release it with dxfg_JavaObjectHandler_release().

Get it with dxfg_PriceLevelService_getAuthOrderSource(); read it with dxfg_AuthOrderSource_getByIds() or dxfg_AuthOrderSource_getByOrderSources().

https://docs.dxfeed.com/orcs/com/dxfeed/orcs/api/AuthOrderSource.html

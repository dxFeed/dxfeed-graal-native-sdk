Detailed Description

The controller of the underlying subscription of a subscription or of a model: attaching it to feeds, the events batch limit, the aggregation period and the executor.

A subscription controller is returned by dxfg_DXFeedSubscription_getSubscriptionController() and by the models (e.g. dxfg_IndexedEventTxModel_getSubscriptionController()). It manages the underlying subscription of that subscription or model. It is marked as experimental in the Java API.

The ownership rules (handles) are the ones of the group Javac. A handle that a function returns (in an [out] parameter) is owned by the caller and is released with dxfg_JavaObjectHandler_release(). A handle that is passed to a function is only read by the SDK: the caller keeps its ownership. Every function returns DXFG_EXECUTE_SUCCESSFULLY (0), or DXFG_EXECUTE_FAIL (-1) on error (an [out] parameter that is NULL is an error as well, and an [out] parameter is written on success only). dxfg_get_and_clear_thread_exception_t() gives the exception.

Attaches the underlying subscription to the specified feed.

The attached subscription receives the events of the feed. It can be attached to several feeds at the same time, but this is rarely necessary and is not recommended.

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]subscriptionControllerThe subscription controller handle.
[in]feedThe feed to attach to.
Returns
DXFG_EXECUTE_SUCCESSFULLY (0) on successful function execution or DXFG_EXECUTE_FAIL (-1) on error. Use dxfg_get_and_clear_thread_exception_t() to determine if an exception was thrown.

int32_t dxfg_SubscriptionController_setAggregationPeriod ( graal_isolatethread_t * thread,
dxfg_subscription_controller_t * subscriptionController,
dxfg_time_period_t * aggregationPeriod )

Sets the aggregation period for data that limits the rate of data notifications. For example, setting the value to 0.1s limits notification to once every 100ms (at most 10 per second). The new aggregation period will take effect during the next iteration of data notification.

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]subscriptionControllerThe subscription controller handle.
[in]aggregationPeriodThe aggregation period for data. The controller does not take the handle: release it with dxfg_JavaObjectHandler_release() when it is no longer needed. For a subscription the period must not exceed 24 hours.
Returns
DXFG_EXECUTE_SUCCESSFULLY (0) on successful function execution or DXFG_EXECUTE_FAIL (-1) on error. Use dxfg_get_and_clear_thread_exception_t() to determine if an exception was thrown.

Java: SubscriptionController.setAggregationPeriod(TimePeriod).

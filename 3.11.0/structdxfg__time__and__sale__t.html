Detailed Description

The time and sale event: a trade or another market event with a price, in a continuous time slice.

It is a time series event, its clazz is DXFG_EVENT_TIME_AND_SALE. Its time is the one in index, there is no separate time field.

int32_t dxfg_time_and_sale_t::flags

The implementation-specific flags: the type (new, correction, cancellation) in bits 0 and 1, the valid tick indicator in bit 2, the extended trading hours indicator in bit 3, the spread leg indicator in bit 4, the aggressor side in bits 5 and 6 and the TradeThroughExempt character in bits 8 to 15; see the getters of TimeAndSale in Java (getType(), isValidTick(), getAggressorSide() and so on).

◆ index

int64_t dxfg_time_and_sale_t::index

The unique per-symbol index of the event: the time of the original event in seconds since the Unix epoch in the higher 32 bits, then the milliseconds part of the time (bits 22 to 31) and the sequence (bits 0 to 21); see TimeAndSale.getIndex() in Java. It can be used to correct or cancel the event later.

Detailed Description

Publishing of events to the local and remote feeds, and the observable subscriptions that tell which symbols the feeds are subscribed to.

The publisher (dxfg_publisher_t) publishes events to the feeds that are connected to it locally or over the network. The observable subscription of the publisher (dxfg_observable_subscription_t) is the set of symbols that the feeds are subscribed to for one event type: add a change listener (dxfg_ObservableSubscriptionChangeListener_new()) to know when to publish the events.

The ownership rules (handles, lists) are the ones of the group Javac. A list that is passed to a function is only read by the SDK: the caller keeps its ownership. A list that a function returns is released by the caller with the function given in the description of the function. The value that a function returns on error is given in its @return. dxfg_get_and_clear_thread_exception_t() gives the exception.

◆ dxfg_DXPublisher_getSubscription()

dxfg_observable_subscription_t * dxfg_DXPublisher_getSubscription ( graal_isolatethread_t * thread,
dxfg_publisher_t * publisher,
dxfg_event_clazz_t eventClazz )

Returns the observable set of the subscribed symbols for the event type.

The symbols of the set are the symbols that the feeds are subscribed to; the set contains the wildcard symbol if there is a subscription to all symbols, and, for a time series subscription, the symbols wrapped with the time of the subscription (dxfg_time_series_subscription_symbol_t). The set may notify its change listeners of the same symbols several times without a removal between the notifications: it happens when the subscription disappears, the cached data is lost and the subscription appears again. On each such notification the data provider is to publish the most recent events of the symbols (dxfg_DXPublisher_publishEvents()).

Returns

◆ dxfg_DXPublisher_publishEvents()

int32_t dxfg_DXPublisher_publishEvents ( graal_isolatethread_t * thread,
dxfg_publisher_t * publisher,
dxfg_event_type_list * events )

Publishes the events to the corresponding feeds.

If the endpoint of the publisher has the publisher role and is connected, the events are delivered to the remote endpoints. The local feed of the endpoint always receives them. A feed receives an event only if it is subscribed to its symbol (or to all symbols with a wildcard, or, for a time series event, with a time series subscription for the time of the event). The published events are not stored and are lost if there is no subscription; the last events of the lasting event types are kept while the subscription to their symbol exists.

The events are serialized by the function: the list and the events are only read, the caller keeps its ownership and can reuse or release them after the function returns.

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]publisherThe publisher handle.
[in]eventsThe events to publish.
Returns
DXFG_EXECUTE_SUCCESSFULLY (0) on successful function execution or DXFG_EXECUTE_FAIL (-1) on error. Use dxfg_get_and_clear_thread_exception_t() to determine if an exception was thrown.

Java: DXPublisher.publishEvents(Collection).

◆ dxfg_ObservableSubscription_addChangeListener()

int32_t dxfg_ObservableSubscription_addChangeListener ( graal_isolatethread_t * thread,
dxfg_observable_subscription_t * sub,
dxfg_observable_subscription_change_listener_t * listener )

Adds the change listener to the observable subscription.

Create the listener with dxfg_ObservableSubscriptionChangeListener_new(); see its description for the callbacks of the listener: they are called on a Java thread, not necessarily the one that added the listener, and the symbols belong to the SDK. If the listener is added to an open subscription, it is notified immediately of the existing subscription state (its symbolsAdded function) before the function returns, and after that of every change. The calls of the listener for one subscription do not overlap. Adding a listener that is already added, or to a closed subscription, does nothing.

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]subThe observable subscription handle.
[in]listenerThe change listener.
Returns
DXFG_EXECUTE_SUCCESSFULLY (0) on successful function execution or DXFG_EXECUTE_FAIL (-1) on error. Use dxfg_get_and_clear_thread_exception_t() to determine if an exception was thrown.

Removes the change listener from the observable subscription.

If the listener was added, it is notified of the removal (its subscriptionClosed function) before the function returns. Removing a listener that is not added does nothing. To be sure that the functions of the listener are not called anymore, release it (dxfg_JavaObjectHandler_release()) or deactivate it (dxfg_NativeListener_deactivate()).

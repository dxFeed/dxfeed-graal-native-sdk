Detailed Description

The control of the on-demand historical tick data replay of an endpoint: start, pause, change the speed and stop the replay, and query its state.

The service is used to switch a feed from the ordinary real-time or delayed data to the replay of the tick-by-tick history of the market data without any change in the code that consumes the events. The replay works only when the endpoint is connected to an on-demand data provider (an address with the "(ondemand:<address>)" component, see dxfg_DXEndpoint_connect()) and the appropriate credentials are provided.

A handle that a function returns is owned by the caller: release it with dxfg_JavaObjectHandler_release() (see the group Javac for the ownership rules). A function that returns int32_t status returns DXFG_EXECUTE_SUCCESSFULLY (0) or DXFG_EXECUTE_FAIL (-1) on error, a function that returns a pointer returns NULL on error, and a function that returns a value gives the value that is stated in its @return on error. The exception is available from dxfg_get_and_clear_thread_exception_t().

typedef struct dxfg_on_demand_service_t dxfg_on_demand_service_t

A handle of a Java OnDemandService object; release it with dxfg_JavaObjectHandler_release().

One service is associated with each endpoint that has the role DXFG_ENDPOINT_ROLE_FEED or DXFG_ENDPOINT_ROLE_ON_DEMAND_FEED: get it with dxfg_OnDemandService_getInstance() or dxfg_OnDemandService_getInstance2(). Releasing the handle does not stop the replay and does not close the endpoint.

◆ dxfg_OnDemandService_getInstance()

dxfg_on_demand_service_t * dxfg_OnDemandService_getInstance ( graal_isolatethread_t * thread)

Returns the on-demand service of the default endpoint with the DXFG_ENDPOINT_ROLE_ON_DEMAND_FEED role.

The endpoint is the application-wide default endpoint of that role (dxfg_OnDemandService_getEndpoint() returns it; dxfg_DXEndpoint_getInstance2() creates a new endpoint instead), which is not connected to any other real-time or delayed data feed. It is created on the first call, is configured by the system properties and is closed by dxfg_system_close_all_and_await_termination(). To switch another feed to the replay and back, use dxfg_OnDemandService_getInstance2() with the endpoint of that feed.

The call fails if the on-demand implementation is not available in the library.

Turns the replay mode on from the specified time with the specified speed.

The feed is disconnected from the other data providers, pre-buffers the historical tick data and replays it as if it came from the data feeds now. After the call dxfg_OnDemandService_isReplay() returns 1, dxfg_OnDemandService_isClear() returns 0, dxfg_OnDemandService_getTime() returns the time that is being replayed and dxfg_OnDemandService_getSpeed() returns speed. The call fails if the replay mode is not supported (see dxfg_OnDemandService_isReplaySupported()) or if the speed is negative.

◆ dxfg_OnDemandService_stopAndClear()

int32_t dxfg_OnDemandService_stopAndClear ( graal_isolatethread_t * thread,
dxfg_on_demand_service_t * service )

Stops the incoming data and clears it without resuming the data updates.

The call works both in the replay mode and for the ordinary data feed: all the incoming data updates are suspended and the current data is cleared. After the call dxfg_OnDemandService_isReplay() returns 0, dxfg_OnDemandService_isClear() returns 1, dxfg_OnDemandService_getTime() returns the last replayed time and dxfg_OnDemandService_getSpeed() returns 0. The ordinary feed is resumed by dxfg_OnDemandService_stopAndResume(), the replay is continued by dxfg_OnDemandService_replay() or dxfg_OnDemandService_replay2().

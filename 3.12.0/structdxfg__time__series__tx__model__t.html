Detailed Description

A handle of a Java TimeSeriesTxModel object; release it with dxfg_JavaObjectHandler_release().

The model is an incremental model of time-series events: it delivers the complete transactions of the events of its symbol from its time to its listener. Close the model with dxfg_TimeSeriesTxModel_close() before releasing the handle: an attached model stays attached to the feed.

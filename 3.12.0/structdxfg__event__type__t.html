dxfg_event_clazz_t clazz

Detailed Description

The base structure of every event: the first field of all the event structures.

clazz tells which event structure the pointer really points to (for example, DXFG_EVENT_QUOTE: dxfg_quote_t); cast the pointer to that structure to read the other fields.

Who creates and releases an event:

  • dxfg_EventType_new() creates an event that the caller owns; all its fields besides clazz and the symbol are zero (not NaN).
  • The SDK creates the events that it passes to a listener or returns as a result. An event passed to a listener belongs to the SDK: it is freed after the listener returns, copy what you need to keep. The events returned as a result belong to the caller.
  • An event of either origin, and a list of events, is released with dxfg_EventType_release() and dxfg_CList_EventType_release(): that frees the structure together with all its strings (the const char * fields, such as the event symbol).

Detailed Description

A list of string to double map entries: the array holds the entries themselves, not pointers to them.

A list that a function returns (dxfg_v4_AdditionalUnderlyings_getMap()) is released with dxfg_v4_string_to_double_map_entry_list_release(), which frees the keys too. A list that the caller passes to a function (dxfg_v4_AdditionalUnderlyings_valueOfMap()) is only read by it and stays with the caller.

Detailed Description

The macros and the functions that every header of the C API uses: the marker of an output parameter, the deprecation marker, the status results and the functions that free memory allocated by the SDK.

The ownership rules of the handles, the strings and the lists are described in the group Javac.

Macro Definition Documentation

◆ DXFG_EXECUTE_FAIL

#define DXFG_EXECUTE_FAIL   ((int32_t)-1)

A result that signals an error that any dxFeed Graal Native SDK function can return: a function that returns int32_t status returns DXFG_EXECUTE_FAIL (-1) when it was terminated by an exception. For information about the thrown exception, see the dxfg_get_and_clear_thread_exception_t() function. Other functions signal an error with another value, which is given in the @return of the function.

◆ DXFG_EXECUTE_SUCCESSFULLY

#define DXFG_EXECUTE_SUCCESSFULLY   ((int32_t)0)

Marks a deprecated function: the compilers warn where it is used. The function still works, see its description for the replacement. A successful result that any dxFeed Graal Native SDK function can return: the status of the functions that return int32_t status, DXFG_EXECUTE_SUCCESSFULLY (0) means that the function was executed without an exception.

◆ DXFG_OUT

#define DXFG_OUT

Marks an output parameter of a function: a pointer to a variable that the function writes the result to, e.g. DXFG_OUT dxfg_endpoint_t **endpoint. The caller passes the address of its own variable, and the variable is written only if the function succeeds (returns DXFG_EXECUTE_SUCCESSFULLY). The macro expands to nothing: it only documents the direction of the parameter in the declaration (the [out] of the documentation).

Typedef Documentation

◆ dxfg_string_to_double_map_entry_t

typedef struct dxfg_string_to_double_map_entry_t dxfg_string_to_double_map_entry_t

A map entry that consists of a string and a double: an element of an array that represents a map from strings to doubles.

An array that a function returns (e.g. dxfg_AdditionalUnderlyings_getMap()) is allocated by the SDK together with the strings of the keys: release it with dxfg_free_string_to_double_map_entries(). An array that is passed to a function (e.g. dxfg_AdditionalUnderlyings_valueOf2()) is only read by the SDK: the caller keeps its ownership.

◆ dxfg_free()

int32_t dxfg_free ( graal_isolatethread_t * thread,
void * pointer )

Frees a block of the unmanaged (GraalVM) memory that a function of the SDK allocated, e.g. the array of doubles that dxfg_PriceIncrements_getPriceIncrements() returns.

Only a block of memory that a function of the SDK allocated and documents to be released with this function can be passed. Do not use the memory after that.

Deprecated
Use dxfg_v4_free().
Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]pointerThe pointer to the unmanaged memory that was returned by the SDK.
Returns
DXFG_EXECUTE_SUCCESSFULLY (0) on successful function execution or DXFG_EXECUTE_FAIL (-1) on error. Use dxfg_get_and_clear_thread_exception_t() to determine if an exception was thrown.

◆ dxfg_free_string_to_double_map_entries()

int32_t dxfg_free_string_to_double_map_entries ( graal_isolatethread_t * thread,
dxfg_string_to_double_map_entry_t * mapEntries,
int32_t size )

Frees an array of string to double map entries that a function of the SDK returned.

It frees the key of every entry and the array itself. Do not use the array and the keys after that. If the array is NULL or size is not positive, the function does nothing (an empty array is not freed) and returns DXFG_EXECUTE_SUCCESSFULLY.

Deprecated
Use dxfg_v4_string_to_double_map_entry_list_release(): dxfg_v4_AdditionalUnderlyings_getMap() returns a list.

[in]mapEntriesThe array of map entries ([string, double] pair) that was returned by the SDK.
[in]sizeThe number of entries in the array, as returned together with the array.
Returns
DXFG_EXECUTE_SUCCESSFULLY (0) on successful function execution or DXFG_EXECUTE_FAIL (-1) on error. Use dxfg_get_and_clear_thread_exception_t() to determine if an exception was thrown.

◆ dxfg_free_strings()

int32_t dxfg_free_strings ( graal_isolatethread_t * thread,
char ** strings,
int32_t size )

Frees an array of C strings that a function of the SDK returned.

It frees every string and the array itself. Do not use the array and the strings after that. If the array is NULL or size is not positive, the function does nothing (an empty array is not freed) and returns DXFG_EXECUTE_SUCCESSFULLY. A list of strings (dxfg_string_list) is not an array of this kind: it is released with dxfg_CList_String_release().

Deprecated
Use dxfg_v4_string_list_release(): the v4 functions return strings in lists.
Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]stringsThe array of the NUL-terminated strings that was returned by the SDK.
[in]sizeThe number of strings in the array, as returned together with the array.
Returns
DXFG_EXECUTE_SUCCESSFULLY (0) on successful function execution or DXFG_EXECUTE_FAIL (-1) on error. Use dxfg_get_and_clear_thread_exception_t() to determine if an exception was thrown.

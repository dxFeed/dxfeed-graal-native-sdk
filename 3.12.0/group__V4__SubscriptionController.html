◆ dxfg_v4_feed_t

typedef dxfg_feed_t dxfg_v4_feed_t

A handle of a Java DXFeed object; release it with dxfg_JavaObjectHandler_release().

Get the feed of the default endpoint with dxfg_DXFeed_getInstance() or the feed of an endpoint with dxfg_DXEndpoint_getFeed(). Releasing the handle does not close the endpoint of the feed.

◆ dxfg_v4_subscription_controller_t

typedef dxfg_subscription_controller_t dxfg_v4_subscription_controller_t

A handle of a Java SubscriptionController object; release it with dxfg_JavaObjectHandler_release().

Get it with dxfg_DXFeedSubscription_getSubscriptionController() or from a model. Releasing the handle does not affect the subscription.

◆ dxfg_v4_SubscriptionController_attach()

int32_t dxfg_v4_SubscriptionController_attach ( graal_isolatethread_t * thread,
dxfg_v4_subscription_controller_t * subscriptionController,
dxfg_v4_feed_t * feed )

Attaches the underlying subscription to the specified feed.

The attached subscription receives the events of the feed. It can be attached to several feeds at the same time, but this is rarely necessary and is not recommended.

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]subscriptionControllerThe subscription controller handle.
[in]feedThe feed to attach to.
Returns
DXFG_EXECUTE_SUCCESSFULLY (0) on successful function execution or DXFG_EXECUTE_FAIL (-1) on error. Use dxfg_v4_get_and_clear_thread_exception() to determine if an exception was thrown.

Java: SubscriptionController.attach(DXFeed).

◆ dxfg_v4_SubscriptionController_setAggregationPeriod()

int32_t dxfg_v4_SubscriptionController_setAggregationPeriod ( graal_isolatethread_t * thread,
dxfg_v4_subscription_controller_t * subscriptionController,
dxfg_v4_time_period_t * aggregationPeriod )

Sets the aggregation period for data that limits the rate of data notifications. For example, setting the value to 0.1s limits notification to once every 100ms (at most 10 per second). The new aggregation period will take effect during the next iteration of data notification.

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]subscriptionControllerThe subscription controller handle.
[in]aggregationPeriodThe aggregation period for data. The controller does not take the handle: release it with dxfg_v4_JavaObjectHandler_release() when it is no longer needed. For a subscription the period must not exceed 24 hours.
Returns
DXFG_EXECUTE_SUCCESSFULLY (0) on successful function execution or DXFG_EXECUTE_FAIL (-1) on error. Use dxfg_v4_get_and_clear_thread_exception() to determine if an exception was thrown.

Java: SubscriptionController.setAggregationPeriod(TimePeriod).

A handle of a Java Executor object; release it with dxfg_JavaObjectHandler_release().

An executor runs the tasks that the SDK gives it, e.g. the calls of the listeners of a subscription or a model. Create it with dxfg_Executors_newFixedThreadPool(), dxfg_Executors_newScheduledThreadPool() or dxfg_ExecutorBaseOnConcurrentLinkedQueue_new().

◆ dxfg_v4_promise_handler_function

typedef dxfg_promise_handler_function dxfg_v4_promise_handler_function

The function that is called when a promise is done.

It is added by dxfg_Promise_whenDone() or dxfg_Promise_whenDoneAsync() and called exactly once, when the promise completes normally, completes exceptionally or is cancelled. The thread that calls it is described in dxfg_Promise_whenDone() and dxfg_Promise_whenDoneAsync(). The function can call the SDK functions with the given thread, e.g. read the result with dxfg_Promise_EventType_getResult().

promise is the pointer that was passed to dxfg_Promise_whenDone() or dxfg_Promise_whenDoneAsync(): the caller owns it, the SDK does not release it and does not copy it, so the caller must keep it valid until the function has been called.

Java: PromiseHandler.promiseDone(Promise).

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]promiseThe promise that is done: the pointer given when the function was added.
[in]user_dataThe pointer that was passed with the function as is; the SDK does not use it.

◆ dxfg_v4_time_series_subscription_t

typedef dxfg_time_series_subscription_t dxfg_v4_time_series_subscription_t

A handle of a Java DXFeedTimeSeriesSubscription object; release it with dxfg_JavaObjectHandler_release().

A time series subscription is a subscription (dxfg_subscription_t) for the events that are time series: pass &sub->sub to the functions of this header. The symbols that are set are wrapped, for the listeners of the changes, with the time from which the events are subscribed (see dxfg_DXFeedTimeSeriesSubscription_setFromTime()). Create it with dxfg_DXFeed_createTimeSeriesSubscription() or dxfg_DXFeed_createTimeSeriesSubscription2().

◆ dxfg_v4_DXFeed_getIndexedEventsIfSubscribed()

int32_t dxfg_v4_DXFeed_getIndexedEventsIfSubscribed ( graal_isolatethread_t * thread,
dxfg_v4_feed_t * feed,
dxfg_v4_event_clazz_t eventClazz,
dxfg_v4_symbol_t * symbol,
const char * source,
DXFG_OUT dxfg_v4_event_type_list ** events )

Returns the indexed events for the event class, symbol and source if there is a subscription for them.

Works only for the indexed events. The function does not make remote calls, it reads the local cache of the feed. The events are in the cache only if an attached subscription is subscribed to the event class, symbol and source (a subscription can also be defined by the endpoint properties). The events are ordered by index, their event flags are always 0. The list is not a consistent snapshot: use dxfg_v4_DXFeed_getIndexedEventsPromise() for it. With the DXFG_ENDPOINT_ROLE_STREAM_FEED role there are never events.

If there is no subscription (Java returns null) or the events have not arrived yet, the result is an empty list (size is 0, elements is NULL); the two cases cannot be told apart by the result. The empty list must be released as well.

Java: DXFeed.getIndexedEventsIfSubscribed(Class, Object, IndexedEventSource).

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]feedThe feed.

int32_t dxfg_v4_Promise_whenDone ( graal_isolatethread_t * thread,
dxfg_v4_promise_t * promise,
dxfg_v4_promise_handler_function promise_handler_function,
void * user_data )

Adds a handler that is called when the promise is done.

The handler is called exactly once: when the promise completes normally, completes exceptionally or is cancelled. There is no way to remove it. If the promise is already done, the handler is called before the function returns, by the calling thread. Otherwise it is called by the thread that completes or cancels the promise. For the promises of the feed requests it is a thread of the executor of the endpoint of the feed; for the others it is the thread that called dxfg_v4_Promise_cancel(), dxfg_v4_Promise_EventType_complete(), etc., or the thread that waits with dxfg_v4_Promise_awaitWithTimeout() when its timeout cancels the promise. Use dxfg_v4_Promise_whenDoneAsync() to run the handler on a given executor.

The handler receives the pointer promise that is passed here: the SDK does not copy or release the structure, so it must stay valid until the handler has been called. user_data is passed to the handler as is, the SDK does not use it.

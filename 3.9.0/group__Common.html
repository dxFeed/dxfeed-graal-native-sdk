Macro Definition Documentation

#define DXFG_EXECUTE_FAIL   ((int32_t)-1)

A result that signals an error that any dxFeed Graal Native SDK function can return. For information about the thrown exception, see the dxfg_get_and_clear_thread_exception_t() function.

#define DXFG_EXECUTE_SUCCESSFULLY   ((int32_t)0)

Marks a deprecated function: the compilers warn where it is used. The function still works, see its description for the replacement. A successful result that any dxFeed Graal Native SDK function can return.

Enumeration Type Documentation

enum dxfg_logging_level_t

Defines a set of standard logging levels that can be used to control logging output.

Enumerator
DXFG_LOGGING_LEVEL_ALL 

Indicates that all messages should be logged.

DXFG_LOGGING_LEVEL_TRACE 

Indicates a highly detailed tracing message.

DXFG_LOGGING_LEVEL_DEBUG 

It is a message level providing tracing debug information.

DXFG_LOGGING_LEVEL_INFO 

It is a message level for informational messages.

DXFG_LOGGING_LEVEL_WARN 

It is a message level indicating a potential problem.

DXFG_LOGGING_LEVEL_ERROR 

It is a message level indicating a serious failure.

DXFG_LOGGING_LEVEL_OFF 

It is a special level that can be used to turn off logging.

Creates a new listener.

```c //

void callback(graal_isolatethread_t *thread, dxfg_logging_level_t level, int64_t timestamp, const char *thread_name, int64_t thread_id, const char *logger_name, const char *message, dxfg_exception_t *exception, const char *formatted_message, void *user_data) { printf("[%" PRId64 "]: %s", thread_id, formatted_message); }

// ...

// Set the logging Java class dxfg_system_set_property(isolate_thread, "log.className", "com.devexperts.logging.InterceptableLogging"); // Turn off logging. dxfg_system_set_property(isolate_thread, "log.level", "OFF");

dxfg_logging_listener_t *listener = {};

dxfg_logging_listener_new(isolate_thread, &callback, NULL, &listener); dxfg_logging_set_listener(isolate_thread, listener);

dxfg_endpoint_t* ep = dxfg_DXEndpoint_getInstance(isolate_thread);

// Turn on logging dxfg_logging_set_log_level(isolate_thread, DXFG_LOGGING_LEVEL_INFO); dxfg_DXEndpoint_close(isolate_thread, ep); dxfg_JavaObjectHandler_release(isolate_thread, &listener->handler); dxfg_JavaObjectHandler_release(isolate_thread, &ep->handler); ```

Parameters
[in]threadThe current GraalVM Isolate's thread.
[in]user_funcThe listener callback.
[in]user_dataThe user data that will be passed to the callback.

Returns
